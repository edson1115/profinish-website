# ProFinish Glass & Body — Landing Page

Files added:
- `index.html` — main landing page

Preview locally:

1. Open `index.html` in your browser directly (works for static preview).
2. Or run a simple local server from the project folder:

```bash
# Install dependencies (first time only)
npm install

# Start local server (http://localhost:3000)
node serve.mjs

# Take a screenshot (requires server running in separate terminal)
node screenshot.mjs
```

Notes:
- Logo and brand images are referenced from `brand_assets/ProFinishLogo.png` and `brand_assets/brand.PNG`.
- Uses Tailwind CSS via CDN for styling.
